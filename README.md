# Guideman

A desktop application for finding, organizing and joining guided tours with local guides.

The project was developed as a university project and focuses on building a complete Java desktop application connected to a relational database.

## Features

- User registration and login
- User profiles
- Creating and managing guided tours
- Scheduling individual tour events
- Searching and filtering available tours
- Joining and leaving tours
- Viewing upcoming and previous tours
- Ratings and reviews
- Persistent storage using MySQL
- DAO-based data access layer

## Technologies

- Java
- JavaFX
- FXML
- MySQL
- Spring JDBC / JdbcTemplate
- Maven
- BCrypt
- JUnit
